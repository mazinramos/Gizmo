\# 🛍️ Gizmo



> A unified e-commerce ecosystem with dedicated interfaces for customers, administrators, and order management.



Gizmo is a multi-interface e-commerce project designed to provide a connected experience for \*\*customers, administrators, and order management operations\*\*.



The project brings the main Gizmo interfaces together inside a single repository, making the system easier to organize, maintain, and develop.



\---



\## ✨ Project Overview



Gizmo is organized into three main applications:



| Application | Description |

|---|---|

| 🛒 \*\*Customer\*\* | Customer-facing shopping experience |

| 🛠️ \*\*Admin\*\* | Administration and store management interface |

| 📦 \*\*OMS\*\* | Order Management System for handling orders and operations |

\## 🎯 Main Goals



\- Provide a unified structure for the Gizmo ecosystem

\- Separate customer, administration, and order-management interfaces

\- Make the project easier to maintain and extend

\- Keep the different system interfaces organized inside one repository

\- Provide a foundation for future shared functionality



\---



\## 🧩 Applications



\### 🛒 Customer



The customer-facing interface of Gizmo.



Its purpose is to provide users with the storefront experience and the customer-side functionality of the platform.



\### 🛠️ Admin



The administrative interface of Gizmo.



It is intended to provide store administrators with tools for managing and operating the platform.



\### 📦 OMS



The Order Management System.



It provides a dedicated interface for managing and handling order-related operations.

\## 🚀 Getting Started



Clone the repository:



```bash

git clone https://github.com/mazinramos/Gizmo.git

```



Enter the project directory:



```bash

cd Gizmo

```



The three interfaces are available in:



```text

customer/

admin/

oms/

```



Each application can be opened independently according to its current implementation.
