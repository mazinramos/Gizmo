<h2>Overview</h2>

<p>
Gizmo is a unified e-commerce project organized around three main interfaces: Customer, Admin, and Order Management.
</p>

<p>
The project brings the different parts of the Gizmo ecosystem together in a single repository for easier organization and development.
</p>

<h2>Applications</h2>

<h3>Customer</h3>

<p>
The customer-facing interface of the Gizmo ecosystem.
</p>

<h3>Admin</h3>

<p>
The administration interface used for managing the platform.
</p>

<h3>OMS</h3>

<p>
The Order Management System interface for handling order-related operations.
</p>

<h2>Project Goals</h2>

<p>
The main goal of Gizmo is to provide a structured foundation for an integrated e-commerce ecosystem while keeping each interface clearly separated.
</p>
